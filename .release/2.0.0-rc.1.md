# PlexonBlacksmith 2.0.0-rc.1

Phase 2 premium-workstation release candidate built from the verified 1.4.1 production baseline.

## Candidate scope

- 54-slot three-page Repair / Combine / Enchant workstation
- MiniMessage/Adventure Plexon presentation language
- exact result and deterministic currency/material previews
- confirmation before donor/book consumption and expensive repairs
- atomic, synchronous paid-operation pipeline with compensating Vault refunds
- strict custom-item combine identity contract; only primary durability changes
- config-driven pricing/features with safe reload and diagnostics
- expanded public quote API and post-commit combine event
- automated regression and distribution verification

## Preserved contracts

- plugin-owned cached real ItemStacks
- repair/enchant clone-based metadata preservation
- Vault as the economy service boundary; TheosisEconomy remains provider authority
- PlexonCore 1/2 lifecycle compatibility and standalone fallback
- unused-input return on close, quit, reload and disable

## Deliberate exclusion

Generic material upgrades are not included. They require explicit ownership-aware recipes/adapters to avoid destroying arbitrary custom PDC/components.

## Certification boundary

This prerelease is source/CI certified only. PlexonCraft runtime certification has not been executed. Do not promote to stable `2.0.0` until the exact candidate JAR passes live PlexonCraft verification.
