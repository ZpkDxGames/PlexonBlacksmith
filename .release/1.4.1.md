# PlexonBlacksmith 1.4.1

Lifecycle compatibility patch for PlexonCore 2.

## Fixed
- Expands the supported Core API range to `>=1.0 <3.0` so the released Core 2 compatibility contract is honored.
- Prevents successful startup from remaining permanently `STARTING` under PlexonCore 2.
- Uses owner-aware Core 2 state transitions and unregister semantics while retaining Core 1 fallback behavior.
- Pins CI to the exact PlexonCore 2.0.4 release JAR and SHA-256.

## Compatibility
- Paper 26.2
- Java 25
- PlexonCore 2.0.4 certification baseline

Blacksmith repair/enchanting gameplay, GUI input caching, transaction behavior and custom-item preservation are otherwise unchanged.
