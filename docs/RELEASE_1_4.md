# PlexonBlacksmith 1.4.0

Core-native migration and transaction-hardening release built directly from the verified production 1.3.0 source.

Highlights:

- PlexonCore 1.x module registration with standalone fallback
- public Blacksmith API and post-success repair/enchant events
- stronger transaction, refund and rapid-click safety
- preserved direct cached-item GUI and exact 1.3 pricing behavior
- custom ItemStack metadata remains clone-preserved
- Java 25 / Paper 26.2 release build

Upgrade by stopping the server, replacing `PlexonBlacksmith-1.3.0.jar`, keeping the plugin folder, and starting the server.
